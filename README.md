# 🤍 Softer RemNote

A soft, minimalist theme for [RemNote](https://www.remnote.com), designed to replace RemNote's harsh whites with gentle lavender and warm beige tones.

## 🎨 Colour Palette

Softer RemNote combines muted lavender, warm beige and subtle neutral accents to create a calm, comfortable reading and studying environment.

| Colour | Hex Code | Purpose |
|---|---|---|
| Warm Beige | `#E9E5DC` | Main theme colour and note editor colour |
| Pale Lavender | `#E9E4ED` | Sidebar background |
| Soft Neutral | `#F3F5F1` | Light accent backgrounds |

## ✨ Features

- Soft lavender and warm beige colour scheme
- Gentle backgrounds that replace harsh whites
- Muted sage accents
- Dark, readable text
- Minimal and distraction-free appearance
- Designed for a calmer RemNote experience

## 📥 Installation

1. Open RemNote.
2. Install or open the theme through its available RemNote theme installation method.
3. Enable Softer RemNote.
4. Enjoy your softer workspace!

## 🌷 Design Philosophy

Softer RemNote is built around a simple idea: studying spaces don't have to be stark white to be clean and functional.

By combining soft lavender, warm beige and muted neutrals, the theme creates a gentler visual environment without unnecessary decoration.

**Less harshness. More softness. A calmer space to study.**
